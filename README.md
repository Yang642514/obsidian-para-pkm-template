# Obsidian PARA+PKM 知识管理系统
一个基于 PARA 方法论和个人知识管理（PKM）系统的 Obsidian 仓库模板，专为新手设计，简单易用。
## ✨ 特性
- 🗂️ **PARA 结构**: 项目-领域-资源-归档的清晰分类
- 📝 **丰富模板**: 预设各种笔记模板，快速创建内容
- 🔧 **插件配置**: 预配置常用插件，开箱即用
- 📊 **自动索引**: 使用 Dataview 自动生成内容索引
- 🎯 **实际案例**: 以写作为主题的完整示例
## 🚀 快速开始
1. 下载或克隆此仓库
2. 用 Obsidian 打开文件夹
3. 阅读 [[快速上手]] 指南
4. 查看 [[插件使用教程]] 了解功能
## 📁 目录结构
`
├── 00-主页/          # 主页和索引页面
├── 01-项目/          # 有明确截止日期的项目
├── 02-领域/          # 需要持续关注的领域
├── 03-资源/          # 知识资源库
├── 04-归档/          # 已完成的项目和过时内容
├── _收件箱/          # 临时想法和待整理内容
├── _模板/            # 各种笔记模板
└── 日记/             # 日记和周记
`
## 🔧 已配置插件
- **Calendar**: 日历视图，快速创建日记
- **Dataview**: 自动生成动态内容列表
- **Tasks**: 强大的任务管理
- **Templater**: 高级模板功能
- **Homepage**: 启动时打开主页
- **Omnisearch**: 全局搜索
