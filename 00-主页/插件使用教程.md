# Obsidian 插件使用教程

本模板不打包第三方插件。先使用 Obsidian 自带功能熟悉 PARA 工作流，再按需要安装社区插件。

## 核心功能

### 日记

模板已将日记目录设置为 `日记/`，文件名格式为 `YYYY-MM-DD`，并使用 `_模板/模板-日记.md`。

使用方式：打开命令面板，运行“日记：打开今天的日记”。

### 模板

模板目录已设置为 `_模板/`。

使用方式：在笔记中打开命令面板，运行“模板：插入模板”，再选择需要的模板。

## 必需的社区插件

动态索引和任务仪表盘依赖两个插件：

| 插件 | 社区插件 ID | 用途 |
| --- | --- | --- |
| Dataview | `dataview` | 生成项目、领域、资源、日记等索引 |
| Tasks | `obsidian-tasks-plugin` | 汇总未完成任务和截止日期 |

安装步骤：

1. 打开“设置 → 第三方插件”。
2. 关闭安全模式并进入社区插件市场。
3. 搜索插件名称，完成安装并启用。
4. 重新打开 `00-主页/主页.md` 检查索引和仪表盘。

### Dataview 示例

```dataview
LIST
FROM "01-项目"
WHERE contains(tags, "project")
SORT file.mtime DESC
```

### Tasks 示例

```tasks
not done
path includes 01-项目
```

## 可选插件

这些插件不会影响模板的基础结构，可按个人习惯安装：

| 插件 | 社区插件 ID | 用途 |
| --- | --- | --- |
| Calendar | `calendar` | 用日历打开日记和周记 |
| Homepage | `homepage` | 启动时打开主页 |
| Omnisearch | `omnisearch` | 增强全文搜索 |
| Recent Files | `recent-files-obsidian` | 查看最近打开的文件 |
| Tag Wrangler | `tag-wrangler` | 批量重命名和整理标签 |

## 常见问题

### 动态索引显示为代码块

确认 Dataview 已安装并启用，然后重新打开对应索引页。

### 任务没有出现在仪表盘

确认 Tasks 已安装并启用，任务使用 `- [ ] 任务内容` 格式，并已保存笔记。

### 日记没有使用模板

在“设置 → 日记”中确认：

- 新建日记的存放位置：`日记`
- 日期格式：`YYYY-MM-DD`
- 日记模板位置：`_模板/模板-日记`

### 想使用其他主题或 AI 插件

请直接从 Obsidian 社区市场安装，并在自己的仓库中维护配置。这个模板不绑定主题，也不保存 API Key、账号或个人插件数据。
