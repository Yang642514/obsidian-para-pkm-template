## 🔧 核心插件

### 1. 日记 (Daily Notes)
**功能**: 自动创建每日笔记
**使用方法**:
- 快捷键: `Ctrl+D` 创建今日笔记
- 自动使用 `_模板/模板-日记.md` 模板
- 笔记保存在 `日记/` 目录下

### 2. 模板 (Templates)
**功能**: 插入预设模板
**使用方法**:
- 命令面板: `Ctrl+P` → 搜索 "模板"
- 选择需要的模板插入到当前笔记

### 3. 标签面板 (Tag Pane)
**功能**: 显示所有标签
**使用方法**:
- 在右侧面板查看所有标签
- 点击标签查看相关笔记

## 🚀 社区插件

### 1. Calendar 日历插件
**功能**: 可视化日历，快速创建日记和周记
**使用方法**:
- 在右侧面板打开日历
- 点击日期创建对应日记
- 点击周数创建周记
- 已配置模板自动应用

**配置说明**:
- 日记模板: `_模板/模板-日记.md`
- 周记模板: `_模板/模板-周记.md`
- 周记保存在: `日记/周记/`

### 2. Dataview 数据视图
**功能**: 自动生成动态内容列表
**使用方法**:
- 查看各个索引页面的自动生成内容
- 支持按标签、日期、状态筛选笔记

**示例查询**:
```dataview
LIST
FROM "01-项目"
WHERE contains(tags, "进行中")
SORT file.mtime DESC
```

### 3. Tasks 任务管理
**功能**: 强大的任务管理和跟踪
**使用方法**:
- 创建任务: `- [ ] 任务内容`
- 设置截止日期: `📅 2024-01-01`
- 设置优先级: `⏫ 高优先级`
- 标记完成: `- [x] 已完成任务`

**任务状态图标**:
- `[ ]` 待办
- `[x]` 完成
- `[-]` 取消
- `[>]` 计划
- `[<]` 开始
- `[!]` 重要

### 4. Templater 模板引擎
**功能**: 高级模板功能，支持动态内容
**使用方法**:
- 命令面板: `Ctrl+P` → "Templater: Create new note from template"
- 选择模板创建新笔记
- 模板会自动填充日期、时间等动态内容

**模板位置**: `_模板/` 目录

### 5. Homepage 主页插件
**功能**: 启动时自动打开主页
**配置**: 已设置为打开 `00-主页/主页.md`

### 6. Omnisearch 全局搜索
**功能**: 强大的全文搜索
**使用方法**:
- 快捷键: `Ctrl+Shift+O`
- 支持模糊搜索、正则表达式
- 可搜索文件内容、标签、属性

### 7. Recent Files 最近文件
**功能**: 快速访问最近打开的文件
**使用方法**:
- 在左侧面板查看最近文件列表
- 点击快速打开

### 8. Tag Wrangler 标签管理
**功能**: 批量管理和重命名标签
**使用方法**:
- 右键点击标签面板中的标签
- 选择重命名、合并或删除操作

## 🚀 快速开始

### 第一次使用
1. **打开主页**: 启动 Obsidian 会自动打开主页
2. **阅读快速上手**: 点击主页中的"快速上手"链接
3. **创建第一个笔记**: 使用模板创建项目、领域或资源笔记

### 日常工作流
1. **每日开始**: 
   - 按 `Ctrl+D` 创建今日笔记
   - 或在日历中点击今天日期
2. **记录想法**: 
   - 临时想法放入 `_收件箱/`
   - 使用相应模板创建正式笔记
3. **整理归档**: 
   - 定期整理收件箱内容
   - 将完成的项目移至归档

### 每周回顾
1. **创建周记**: 在日历中点击周数
2. **回顾本周**: 使用周记模板进行回顾
3. **计划下周**: 在周记中制定下周计划

## ❓ 常见问题

### Q: 如何修改模板？
A: 直接编辑 `_模板/` 目录下的模板文件即可。

### Q: 日记没有自动应用模板？
A: 检查设置中的日记模板路径是否正确设置为 `_模板/模板-日记.md`。

### Q: Dataview 查询不显示内容？
A: 确保：
1. Dataview 插件已启用
2. 查询语法正确
3. 目标文件夹中有符合条件的笔记

### Q: 任务不显示在任务索引中？
A: 确保：
1. 任务格式正确: `- [ ] 任务内容`
2. Tasks 插件已启用
3. 任务所在笔记已保存

### Q: 如何自定义快捷键？
A: 设置 → 快捷键 → 搜索对应功能进行设置。

### Q: 插件加载失败怎么办？
A: 
1. 检查插件是否已启用
2. 重启 Obsidian
3. 检查插件版本兼容性

## 📚 进阶使用

### 自定义 Dataview 查询
在任何笔记中使用以下格式创建动态列表：

```dataview
TABLE file.mtime as "修改时间"
FROM "03-资源"
WHERE contains(tags, "重要")
SORT file.mtime DESC
LIMIT 10
```

### 高级任务管理
结合标签和日期创建复杂的任务查询：

```tasks
not done
path includes 01-项目
(due before tomorrow) OR (priority is high)
```

### 模板变量
在 Templater 模板中使用动态变量：
- `{{date}}` - 当前日期
- `{{time}}` - 当前时间
- `{{title}}` - 文件标题
